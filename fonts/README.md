Noto Sans SC, from https://github.com/google/fonts/tree/main/ofl/notosanssc
Licensed under SIL Open Font License 1.1; see OFL.txt. The bundled font is embedded as a subset in exported PDFs, without a network dependency. It covers Latin, kana and CJK names. CJK glyph forms follow the Simplified Chinese font design; locale-specific Japanese/Traditional typography and complex-script shaping are not promised. Unsupported characters fail before browser issuance, rather than becoming missing-glyph boxes.

Original upstream variable font SHA-256: `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`.

The upstream variable font was instantiated at weight 400 (Regular) with fontTools. This avoids its Thin default in PDF renderers. The OFL license is preserved. Regular derivative SHA-256: `22d077d69aefac0011e8093ac34c0003073aa051eb3f3f306570ee9159117edd`.
