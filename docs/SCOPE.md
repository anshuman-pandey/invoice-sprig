# Scope and acceptance

Single-owner, self-hosted invoice ledger: immutable numbered invoices, exact-cent totals, manual payment status with history, PDF/JSON download and completed-time import. No tax-compliance, payment-verification, email-delivery or team-account claims.

Implemented: owner browser workflow, retry-safe issuance, six UI languages, Latin/kana/CJK PDF text, backup and fresh-volume recovery.

Remaining: independent repository creation/publication, hosted HTTPS with persistent storage, native-speaker review and optional locale-specific PDF typography.
